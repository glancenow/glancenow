# 設定の書き方

GlanceNow の設定は、1つのファイルに入っています。

- 場所：ホームフォルダの下の `.glancenow/config.json`（環境変数 `GLANCENOW_HOME` を決めている時は、そのフォルダの中）
- 形：JSON
- 場所を確かめる：`python3 <道具の場所>/scripts/glancenow.py config-show`

ファイルが無い時は、標準の設定で動きます。全部の項目を書いたファイルは、`config-init` で作れます。

## 設定を変える4つの入口

| 入口 | やり方 | 残る場所 |
|---|---|---|
| 最初の質問 | 「GlanceNow の設定を始めて」と言う | 設定ファイル |
| AI に頼む | 「GlanceNow を暗い画面にして」のように言う | 設定ファイル |
| 自分で書く | `config.json` を開いて書き換える | 設定ファイル |
| 画面から | 画面の右上の「変える」を押す | その画面を開いたブラウザの中 |

画面から変えた事と設定ファイルが食い違う時は、次の決まりで出します。

- 設定ファイルを書き換えていない間は、画面で変えた方を出す。
- 設定ファイルの「まとまり」（`rooms`・`items`・`sections`・`look` の4つ）を書き換えると、そのまとまりの画面での変更は外れて、設定ファイルの方を出す。外した時は、画面の上に知らせが出る。ほかのまとまりの画面での変更は残る。
- そのあと画面でもう一度変えれば、また画面の方を出す。

## 項目の一覧

### rooms（載せる部屋と並び）

| 項目 | 書ける値 | 標準 | 意味 |
|---|---|---|---|
| `show` | `"recent30"`／`"all"`／`"list"` | `"recent30"` | 載せる部屋。この30日に動いた部屋／全部／`list` に書いた部屋だけ |
| `list` | `["…", "…"]` | `[]` | `show` が `"list"` の時に載せる部屋 |
| `hide` | `["…", "…"]` | `[]` | 載せない部屋（`show` が何でも効く） |
| `show_temp` | `true`／`false` | `false` | OS の一時フォルダの下にある部屋を載せるか。`false` の間は、`show` が何でも載らない |
| `recent_days` | `1` から `30` までの数 | `2` | 節「最近動いた部屋」に入れる日数（この日数のうちに動いた部屋を、カードで出す） |
| `order` | `"last_active"`／`"name"`／`"manual"` | `"last_active"` | 並び。最後に動いた順／名前の順／`manual_order` に書いた順 |
| `manual_order` | `["…", "…"]` | `[]` | `order` が `"manual"` の時の並び。書いていない部屋は、後ろに新しい順で続く |
| `names` | `{"部屋": "画面に出す名前"}` | `{}` | 画面に出す名前を変える |

部屋は、次のどれでも書けます。

- フォルダの名前（例 `"shop-site"`）
- フォルダの場所（例 `"/home/me/work/shop-site"`。Windows では `\` を `\\` と書く）
- id（`rooms` の入口が出す10文字。同じ名前の部屋が2つある時に使う）

OS の一時フォルダ＝Windows では `AppData\Local\Temp` と `Windows\Temp`、Mac・Linux では `/tmp`・`/var/tmp`・`/var/folders`、それと環境変数 `TEMP`・`TMP`・`TMPDIR` が指す場所です。その下で Claude Code を動かしたフォルダは、試しに作った物が多いので、標準では載せません。載せる時：

    python3 <道具の場所>/scripts/glancenow.py config-set rooms.show_temp=true

`show` が `"recent30"` の時、30日より前に動いたきりの部屋は載りません。その数だけを、「止まっている部屋」の節の終わりに1行で出します（部屋の名前は出しません）。

### items（部屋ごとに出す項目）

どれも `true`（出す）か `false`（隠す）。標準は全部 `true`。

| 項目 | 中身 |
|---|---|
| `status` | 状態（動かしている／維持だけ／休眠） |
| `next` | 次の一手 |
| `waiting` | 判断待ち |
| `last_active` | 最後に動いた日時 |
| `last_prompt` | 最後に頼んだ文（会話で最後に送った文の先頭60字。10字より短い時は、1つ前に送った文の先頭40字も並べる） |

`last_prompt` を `false` にしている間は、その文を控えません（控えてあった文も消します）。

裏で走った作業の終わりの知らせ（`<task-notification>` で始まる文）など、人が打っていない文は「最後に頼んだ文」に数えません。貼り付けた文の印（`<pasted_content …>`）は外して、中身を出します。

### sections（節の構成）

出す節を、出す順に並べます。標準は `["waiting", "recent", "all", "stalled"]`。

| 名前 | 節 |
|---|---|
| `waiting` | 判断待ち（返事を待っている事の一覧） |
| `recent` | 最近動いた部屋（この2日・カード。日数は `rooms.recent_days`。区切りの記録がある部屋だけをカードにする） |
| `all` | 全部の部屋（1部屋1行。区切りの記録が無い部屋も、ここに出る） |
| `stalled` | 止まっている部屋（21日以上動きなし・畳んで出す） |

### look（見た目）

| 項目 | 書ける値 | 標準 |
|---|---|---|
| `theme` | `"auto"`（PCの設定に合わせる）／`"light"`／`"dark"` | `"auto"` |
| `font_size` | `"small"`／`"normal"`／`"large"` | `"normal"` |
| `accent` | `"blue"`／`"green"`／`"orange"`／`"purple"`／`"pink"`／`"gray"`／`"#rrggbb"` の形の色 | `"blue"` |

### checkpoint（区切りの後の1行）

| 項目 | 書ける値 | 標準 | 意味 |
|---|---|---|---|
| `after_skills` | `["…", "…"]` | `["区切り"]` | 区切りとして見るスキルの名前。このスキルが動いた返事で、部屋の1行がまだ書かれていなければ、返事の終わりに AI に1行を書かせる |

- 「区切り」と言わなくても、ほかの仕組み（フック・AI の判断）でそのスキルが動いた時に効きます。
- プラグインのスキルは、`プラグイン:スキル` の形でも、`:` の後ろだけでも書けます。
- 空の一覧（`[]`）にすると、返事の終わりに頼まなくなります（「区切り」と言った時の1行は、今までどおり書かれます）。
- 最初の質問が済むまでは、頼みません。
- 画面には関わらないので、画面の「変える」では変えられません。

## 例

```json
{
  "version": 1,
  "rooms": {
    "show": "all",
    "hide": ["old-notes"],
    "order": "manual",
    "manual_order": ["shop-site", "report"],
    "names": {"shop-site": "お店のサイト"}
  },
  "items": {
    "last_prompt": false
  },
  "sections": ["waiting", "recent", "all"],
  "look": {
    "theme": "dark",
    "font_size": "large",
    "accent": "green"
  }
}
```

書いていない項目は、標準の値になります。

## 書き間違えた時

読めない所がある間は、前に読めた設定（一度も読めていなければ標準の設定）で画面を出し、画面の上に「何行目の、何が読めないか」を出します。直して保存すると、次に画面が作り直された時に知らせが消えます。

すぐ確かめる時：

    python3 <道具の場所>/scripts/glancenow.py config-check

| 知らせ | 直し方 |
|---|---|
| ◯行目の終わりに、カンマ（,）が足りません | その行の終わりに `,` を足す |
| look.theme は auto／light／dark のどれかで書きます | 書ける値のどれかに直す |
| items.next は true か false で書きます | `"true"` のように `"` で囲まず、`true` と書く |
| 知らない項目 … があります（使いません） | 名前の書き間違い。使われないだけで、ほかの設定は効く |

## コマンドで変える

ファイルを開かずに変える入口もあります（AI に頼んだ時は、これを使っています）。書ける値かどうかを確かめてから書き、読めない形になる時は書きません。

    python3 <道具の場所>/scripts/glancenow.py config-set look.theme=dark
    python3 <道具の場所>/scripts/glancenow.py config-set rooms.show=all rooms.hide=old-notes,tmp
    python3 <道具の場所>/scripts/glancenow.py config-set sections=waiting,recent,all
    python3 <道具の場所>/scripts/glancenow.py config-set rooms.names.shop-site=お店のサイト
    python3 <道具の場所>/scripts/glancenow.py config-set checkpoint.after_skills=区切り,wrap-up
    python3 <道具の場所>/scripts/glancenow.py build

一覧の項目は、カンマで区切って全体を書きます。`rooms.names.<部屋>=` のように値を空にすると、付けた名前を外します。
