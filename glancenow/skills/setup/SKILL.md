# GlanceNow の最初の設定（6問）

GlanceNow は、作業フォルダ（以下「部屋」）ごとの今を、1枚の画面にまとめて出す道具です。
このスキルは、使う人に6つの質問をして、その人用の画面を作ります。

## 道具

使うのは、次の1つだけです（以下「道具」）。python3 が無い所では、python3 を python に置き換えます。

    python3 "${CLAUDE_PLUGIN_ROOT}/scripts/glancenow.py" <入口> [引数]

設定ファイルを直接書き換えません。設定は `config-set` で入れます（書ける値は、道具が確かめます）。

## 聞き方の決まり

- 質問は**1問ずつ**、選択形式（AskUserQuestion）で出す。1回に1問。まとめて出さない。
- どの問いにも「標準のまま」を置く。おすすめの印は付けない。
- 選択形式を出せない時は、同じ選択肢に番号を付けて文で1問ずつ聞き、番号で答えてもらう。
- 答えが出るたびに、すぐ `config-set` で入れる（途中でやめても、そこまでの答えが残る）。
- 使う人が途中でやめた時（「もういい」「あとは標準で」など）は、残りを聞かずに「終わり方」へ進む。
- 道具の出力は、使う人には見えていない。部屋の一覧などを見てもらう時は、返事の文の中に書く（「上の一覧」とは言わない）。
- 文で聞く形になった時は、2問目から、道具を実行してよいかの確認が出ることがある。1問目を聞く時に「途中で実行の確認が出たら、許可を選んでください」と1行添える。

## 手順

### 1. 準備

1. `scan` を実行する（会話の記録から部屋を見つける）。
2. `rooms` を実行する。番号つきの部屋の一覧と、「この30日に動いた部屋の数」「全部の数」が出る。
3. `config-init` を実行する（設定ファイルが無ければ、標準の値で作る。もうあれば何もしない）。
4. 使う人に1行で伝える：「6つ聞きます。どれも『標準のまま』を選べます。」

### 2. 6つの質問

**1問目 載せる部屋**（どの部屋を画面に載せますか）

| 選択肢 | 入れる設定 |
|---|---|
| 標準のまま（この30日に動いた部屋・◯部屋） | `rooms.show=recent30` |
| 全部の部屋（◯部屋） | `rooms.show=all` |
| 自分で選ぶ | 下の「自分で選ぶ」 |

◯には、`rooms` が出した数を入れる。
「自分で選ぶ」の時：`rooms` が出した一覧を、返事の文の中に書いて見せる（1部屋1行で、番号・名前・最後に動いた時。全部の部屋を書く）。そのあとで、載せる部屋の番号を答えてもらう（例「1,2,5」）。
`config-set rooms.show=list rooms.list=<id>,<id>,…` で入れる（部屋は id で書く）。

**2問目 並び**（部屋を、どの順に並べますか）

| 選択肢 | 入れる設定 |
|---|---|
| 標準のまま（最後に動いた順） | `rooms.order=last_active` |
| 名前の順 | `rooms.order=name` |
| 自分で決める | 下の「自分で決める」 |

「自分で決める」の時：1問目で載せると決まった部屋を番号つきで見せ、上から並べたい順に番号を答えてもらう。
`config-set rooms.order=manual rooms.manual_order=<id>,<id>,…` で入れる。書かれなかった部屋は、後ろに新しい順で続く。

**3問目 部屋ごとに出す項目**（部屋ごとに、何を出しますか）

項目は5つ：状態／次の一手／判断待ち／最後に動いた日時／最後に頼んだ文（会話で最後に送った文の先頭60字）。

| 選択肢 | 入れる設定 |
|---|---|
| 標準のまま（5つとも出す） | 何も入れない |
| 「最後に頼んだ文」だけ出さない | `items.last_prompt=false` |
| 自分で選ぶ | 5つに番号を付けて見せ、出す物の番号を答えてもらう。出さない物を `items.<名前>=false` で入れる |

項目の名前：`status`（状態）・`next`（次の一手）・`waiting`（判断待ち）・`last_active`（最後に動いた日時）・`last_prompt`（最後に頼んだ文）。
「最後に頼んだ文」を出さない設定の間は、GlanceNow はその文を控えません。聞く時に、この事を1行添える。

**4問目 節の構成**（画面を、どの節に分けますか）

節は4つ：判断待ち／最近動いた部屋（この7日）／全部の部屋／止まっている部屋（21日以上動きなし）。

| 選択肢 | 入れる設定 |
|---|---|
| 標準のまま（4つとも・この順） | 何も入れない |
| 「止まっている部屋」を出さない | `sections=waiting,recent,all` |
| 自分で選ぶ | 4つに番号を付けて見せ、出す節の番号を、上から出したい順に答えてもらう。`sections=<名前>,<名前>,…` で入れる |

節の名前：`waiting`（判断待ち）・`recent`（最近動いた部屋）・`all`（全部の部屋）・`stalled`（止まっている部屋）。

**5問目 見た目**（明るい画面・暗い画面と、色）

| 選択肢 | 入れる設定 |
|---|---|
| 標準のまま（PCの設定に合わせる・色は青） | 何も入れない |
| いつも明るい画面 | `look.theme=light` |
| いつも暗い画面 | `look.theme=dark` |
| 色も選ぶ | 明るさ（PCに合わせる＝`auto`／明るい＝`light`／暗い＝`dark`）と、色（青＝`blue`／緑＝`green`／オレンジ＝`orange`／紫＝`purple`／ピンク＝`pink`／グレー＝`gray`）を番号で答えてもらう。`look.theme=… look.accent=…` で入れる |

**6問目 文字の大きさ**

| 選択肢 | 入れる設定 |
|---|---|
| 標準のまま（ふつう） | 何も入れない |
| 小さめ | `look.font_size=small` |
| 大きめ | `look.font_size=large` |

### 3. 終わり方

1. `config-check` を実行する。「読めない所」が出たら、その項目を `config-set` で入れ直す。
2. `setup-done` を実行する（質問が済んだ事を覚えて、画面を作る）。
3. `open` を実行する（画面を、いつものブラウザで開く）。出力の「画面:」の場所を、使う人に伝える。
4. 決めた事を2〜3行でまとめる（標準のままにした所は「標準」と書く）。
5. 最後に、次の1行をそのまま伝える：

   作業の区切りで「区切り」と言うと、この部屋の今が画面に出ます。

設定は、あとからいつでも変えられる事も1行で伝える（画面の「変える」ボタン／「GlanceNow の設定を変えて」と頼む／設定ファイルを自分で書く）。
