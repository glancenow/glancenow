# 区切り：この部屋の今を、1行で記録する

## ほかの「区切り」と重なる時

「区切り」という言葉で動く物が、このスキルのほかにもある時（使う人が自分で入れたスキル・作業フォルダの決まりなど）は、次の順で進めます。

1. ほかの方の手順を、先に全部済ませる。
2. 最後に、このスキルの手順で1行を書く。

このスキルだけを動かして終わりにしません。ほかの方の手順を、このスキルで置き換えません。

「区切り」のスキル（設定の `checkpoint.after_skills` に書いた名前）が動いたのに、この1行が書かれないまま返事が終わりそうな時は、GlanceNow が返事の終わりに「1行を書いてください」と頼みます。その時は、ほかの方の手順はもう済んでいるので、このスキルの手順だけをします。

## 道具

使うのは、次の1つだけです。python3 が無い所では、python3 を python に置き換えます。

    python3 "${CLAUDE_PLUGIN_ROOT}/scripts/glancenow.py" note --status <状態> --next '<次の一手>' [--waiting '<判断待ち>'] [--memo '<一言>']

今の作業フォルダで実行します（別のフォルダの記録を書く時だけ `--cwd '<場所>'` を付ける）。

## 手順

1. この会話から、次の4つを決める。使う人には聞かない。
   - **状態**：`動かしている`（作業が進んでいる）／`維持だけ`（動いているが、手を入れていない）／`休眠`（しばらく触らない）。迷う時は `動かしている`。
   - **次の一手**：次にこの部屋で最初にする事を、1文で。動詞で終える（例「在庫の表に合計の列を足す」）。
   - **判断待ち**：使う人の返事や決定を待っている事がある時だけ、1文で。無ければ付けない。
   - **一言**：残しておきたい事がある時だけ。無ければ付けない。
2. 道具を1回実行する。文は ' ' で囲む。文の中に ' がある時は、’ に置き換える。
3. 道具が出した「記録しました…」の行を、そのまま使う人に見せる。ほかの説明は足さない。
   「画面は、最初の質問が済むと出ます」と出た時は、その行も見せる。

## 決まり

- 1回の区切りで書くのは1行だけ。
- 状態・次の一手に、会話に無い事を書かない。
- 記録は GlanceNow 用の置き場所に書かれる。作業フォルダの中には、何も足さない。
